# Save Your Pet
Este programa está diseñado para gestionar de las operaciones de una clínica veterinaria. Su objetivo es ofrecer un software que permita a los administradores,
veterinarios y personal de la clínica llevar un control adecuado de los animales, propietarios, consultas y servicios prestados.

### Contenido 

El programa PetsMain es una aplicación interactiva de consola para la gestión integral de una clínica veterinaria. A través de un menú principal, el programa permite al usuario seleccionar diferentes opciones que cubren varias áreas clave de la clínica. A continuación, se detalla el contenido del programa basado en las diferentes funcionalidades implementadas en las opciones del menú:

**Estructura general**:
- Diagrama ER:
- Diagrama UML: 
- Menú principal: presenta las opciones disponibles para el usuario y permite navegar entre ellas. Después de cada selección, el programa realiza la operación correspondiente y luego vuelve a mostrar el menú para continuar.
  
**Funciones principales**:
- Permite registrar y actualizar información de mascotas y propietarios.
- Muestra el inventario de suministros (como medicamentos, alimentos, etc.).
- Permite agregar nuevos productos, actualizar stock. 
- Facilita la creación de nuevos servicios veterinarios. 
- Ofrece funciones como la generación de facturas y visualización del historial de facturación. 
- Permite acceder al historial de las mascotas y al de dueños. 
- Genera diversos reportes.
- Entre otras más.

## Instalación :wrench:
### Requisitos 
- Git. 
- NetBeans. 

### Paso a paso 
1. Entra a la carpeta donde deseas clonar el repositorio.
2. Abre el terminal y copia el siguiente código: <br><br>
   ```
   git clone https://github.com/DLeonardoG/LittlePets
   ```
3. Entra a NetBeans y da clic en "Open Project" 
4. Busca el proyecto en la carpeta donde lo clonaste y da clic.
5. Ejecuta la clase main PetMain
